# KOLYAN: ESCAPE FROM THE CLASSROOM

Мобильная 3D-игра от третьего лица (Three.js + Vite). Колян ростом 17 см должен сбежать из аудитории:
собрать 3 предмета, добраться до стола преподавателя и открыть портал, не попавшись трём монстрам.

## Запуск

```bash
cd kolyan-game
npm install
npm run dev      # dev-сервер, открой адрес с телефона в той же Wi-Fi сети
npm run build    # сборка в ../kolyan/ (один index.html + PWA-файлы)
```

Сборка — это папка `kolyan/` в корне репозитория: самодостаточный `index.html` (≈590 КБ, three.js внутри),
`manifest.webmanifest`, `sw.js`, иконки. Её можно залить на любой статический хостинг.

### GitHub Pages
В репозитории уже есть `.nojekyll`. Settings → Pages → Deploy from a branch → `main` / `(root)`.
После мержа игра доступна по адресу `https://<user>.github.io/blocks/kolyan/`.

### Другой хостинг
Netlify / Vercel / Cloudflare Pages: перетащи папку `kolyan/`. Нужен HTTPS — без него не работают PWA и полноэкранный режим.

## Управление (сенсор)
- левая половина экрана — динамический джойстик;
- правая половина — камера (работает одновременно с джойстиком и кнопками);
- JUMP (у края превращается в CLIMB), CLIMB, ACTION, RUN и CROUCH (переключатели);
- в настройках: чувствительность камеры, громкость, качество LOW/MEDIUM/HIGH, автобег, инверсия, FPS.

Клавиатура (только для отладки на ПК): WASD, мышь, Space, Shift, C, E, F.

## Устройство кода
| файл | что внутри |
|---|---|
| `src/level.js` | аудитория: парты, стулья, доска, экран, окна с жалюзи, кафедра, стол преподавателя, книги, линейки-мосты, чекпоинты |
| `src/physics.js` | AABB-коллизии, рейкасты, поиск выступов для карабканья |
| `src/player.js` | контроллер и процедурные анимации Коляна |
| `src/monsters.js` | ИИ: Patrol / Suspicious / Chase / Search / Return, зрение (дистанция + FOV + рейкаст), слух |
| `src/nav.js` | сетка навигации и BFS-пути для монстров |
| `src/camera.js` | камера от третьего лица с обходом препятствий |
| `src/input.js` | мультитач: джойстик, камера, кнопки |
| `src/audio.js` | синтезированные звуки (WebAudio, без файлов) |
| `src/main.js` | цикл игры, задания, HUD, меню, адаптивное разрешение |

Все модели собраны из примитивов (стилизация, без фото-текстур). Оптимизация: инстансинг мебели,
склейка мешей персонажей (~60–90 draw calls), тени только у одного источника, адаптивное разрешение рендера.
