# №67: ЧЕРЕЗ ВСЕЛЕННЫЕ — раскадровка

Исходник: 848×480, 30 fps, 8.37 с. Бросок #67 — 4.58 с, мяч в сетке — 5.80 с, рёв трибун — 5.9 с.
Выход: 1920×1080, 60 fps, H.264 + AAC, 16.29 с. Музыка 140 BPM (бит = 0.4286 с), дроп = свиш.

Идея: обычный любительский бросок становится событием мультивселенной: комикс-обложка → перемотка → чутьё → полёт → SWISH → тот же момент в 4 вселенных → страница комикса.

| # | Время | Варианты (выбран — **жирным**) | Решение |
|---|---|---|---|
| 1 | 0–1.71 | чёрный экран+печать текста / слайд панелей / **обложка-стоп-кадр броска + перемотка** / портал | Стоп-кадр в момент отрыва мяча, халфтон, заголовок «№67 / ЧЕРЕЗ / ВСЕЛЕННЫЕ» влетает на 3 бита, 4-й бит — глитч-перемотка назад |
| 2 | 1.71–5.14 | чистый рилтайм / **рилтайм ×1.25, лёгкий комикс-грейд, плашка рассказчика** / сплит-экран | «ТЕМ ВРЕМЕНЕМ, ГДЕ-ТО В МУЛЬТИВСЕЛЕННОЙ…», плавный дрейф камеры, тег «№67» над героем |
| 3 | 5.14–6.86 | зум+стоп / **наезд на героя → стоп-кадр с «паучьим чутьём» → slow-mo прыжок** / ретикл-прицел | Волнистые линии вокруг головы, дуотон, плашка «ЧУТЬЁ ГОВОРИТ: БРОСАЙ», музыка уходит в фильтр |
| 4 | 6.86–8.57 | общий план / **THWIP-стоп на отрыве → свип-панорама к кольцу с моушн-блюром, пунктир траектории** / split | Анимация «на двойках» (12 к/с), райзер, мяч падает в кадр сверху |
| 5 | 8.57–9.43 | белая вспышка / **удар-зум в кольцо, CMY-халфтон, хроматика, глитч, спидлайны, SWISH!** / инверсия | Дроп музыки + реальный рёв зала |
| 6 | 9.43–11.14 | повтор с разных углов / **4 косые панели: НУАР, ПОП-АРТ, 8-БИТ, НЕОН — по одной на бит** / калейдоскоп | «В КАЖДОЙ ВСЕЛЕННОЙ — ЧИСТО.» |
| 7 | 11.14–13.71 | стоп / **панели разлетаются, живое празднование, отъезд камеры** / титры | Рилтайм ×1.0 |
| 8 | 13.71–16.29 | затемнение / **кадр сжимается в панель страницы комикса + 2 панели-флешбэка, «ПРОДОЛЖЕНИЕ СЛЕДУЕТ…»** / логотип | Финальный аккорд и хвост |

Шрифты: Bangers (звукоподражания, OFL), Rubik Mono One (кириллица, OFL). Музыка и SFX синтезированы с нуля (numpy), без чужих треков.
